# 微信聊天导出 Skill + Windows 图形界面

## 功能

直接将 **Windows 微信 4.x** 本机保存的**群聊和好友聊天记录**导出为 **TXT、JSON**，供 Codex 等软件读取，保留发言人、时间、正文和引用。支持按群名、好友备注／昵称或会话 ID 选择，按时间范围或全部历史导出，**无需转发到文件传输助手**。

只涵盖当前电脑已有的记录；图片、语音、视频及附件保留类型和可解析描述，暂不导出文件本体。原有的文件传输助手导出和合并转发展开功能仍可使用。

## 图形界面：普通用户直接使用

本分支增加了一个轻量 Windows 图形界面，不需要安装额外 GUI 框架：

- 自动发现 `Documents/xwechat_files` 下的本机微信账号；
- 只读搜索会话名称，支持多选群聊和好友；
- 支持最近若干分钟／小时／天、指定时间或全部历史；
- 自定义输出目录，并显示导出状态和错误原因；
- 输出 TXT、JSON 和验证报告。

### 一键启动

1. 安装 **Python 3.11 或更新版本**，安装时勾选 `Add Python to PATH`。
2. 保持 Windows 微信 4.x 运行并登录。
3. 下载或克隆本仓库，双击 `启动微信聊天导出器.cmd`。

首次启动会在 `%LOCALAPPDATA%/wechat-chat-export/venv` 创建独立环境并安装锁定版本依赖；后续启动直接打开界面。默认输出到仓库目录下的 `导出结果`，该目录已被 Git 忽略。

图形界面只是本仓库导出脚本的本地封装，不会复制密钥、上传聊天内容或修改微信数据。点击“列出会话”只读取会话元数据；点击“开始导出”后才读取明确选择的会话和时间范围。

## 怎么调用

保持电脑微信已登录，在安装了本 skill 的 Codex 会话中发送（将示例名称替换为实际群名和好友备注）：

```text
使用 $wechat-chat-export，直接导出“项目讨论群”和好友“张三”
最近 60 分钟的聊天记录，保存为 TXT 和 JSON。
```

需要全部记录时，把时间范围改为“本机保存的全部历史”；不确定名称时，可以先说“列出名称包含 XXX 的会话”。遇到重名会先列出候选供你选择，多个会话分别保存。也可以指定其他时间范围和保存位置。
